**Teste o site aqui: https://dungeons-and-dragons-pesquisa.vercel.app/**

**O que é?**

O Inventário de D&D é a sua ferramenta onde você pode pesquisar itens do jogo de dungeons and dragons e ler uma breve descrição do item e recebe um link direto para a wiki do item do jogo! 

**Como funciona?**
**(Itens Pesquisaveis: Adaga, Espada Longa, Arco Longo)**
**Pesquise por itens:** Digite o nome do item que você procura na barra de pesquisa.
**Explore os resultados:** Uma lista de itens relevantes será exibida, com detalhes como nome, descrição e links para mais informações.

**Tecnologias utilizadas:**

* **HTML:** Para a estrutura da página.
* **CSS:** Para estilizar a interface.
* **JavaScript:** Para a lógica da aplicação e as buscas.
